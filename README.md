# Laravel 8 E-Commerce

Full e-commerce platform built with Laravel 8.

## Tech Stack
- PHP / Laravel 8
- MySQL
- Bootstrap
- Blade Templates

## Features
- Product catalog
- Shopping cart
- Order management
- Admin dashboard
- Authentication

## Setup
```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```
